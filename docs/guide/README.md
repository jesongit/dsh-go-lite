- [升级与旧本地数据](zh/04-legacy-data.md)：兼容签名、外部备份、私有旧数据与手动迁移

- [宠物](zh/06-pets.md)：选择宠物、气泡、App 外显示
- [分享与回放](zh/07-sharing.md)：链接、图片、文件、文字与接着聊
- [插件](zh/08-plugins.md)：安装、开关、更新、卸载、设置与远端桥接
- [外观](zh/09-appearance.md)：明暗、配色、图标、启动画面、壁纸、对话字号

DSH Go is a remote client. Add and select an SSH or DSH Remote host first; no DSH runtime is installed on the phone. Read the legacy-data page before upgrading.

- [Web mode](en/05-web.md): SSH Web access, switching interfaces and phone layout

- [Sharing and replay](en/07-sharing.md): links, images, files, text and continuing a chat
