# 升级与旧本地数据

DSH Go 现在连接电脑或服务器上的 DSH，不再在手机上安装或启动 Linux、PRoot、Direct 或 DSH 引擎。旧的本机 DeepSeek 账号登录和 AI 手机操控已移除；用于远程连接的 DSH Remote 账号登录保留。

## 升级后的变化

旧配置中选中的本机主机会变成“未选择”。首次使用且没有主机、删除当前主机、退出当前 DSH Remote 账号后，也会保持未选择。App 不会替你选择另一台远程主机；发送内容前请明确选择目标。

升级不会自动删除、重置、上传或迁移旧 Linux 主目录、对话、工作区、插件及凭据。文件仍留在 Android 的 App 私有数据中。保留文件不等于已经迁移；新版 App 不能运行旧环境，也不能把它作为主机浏览。

## 更换安装前保留数据

1. 卸载、清除 App 数据或更换签名前，先做好并核验外部备份。Android 覆盖更新需要兼容签名和更高的构建号；debug 签名包不能覆盖不同签名的官方包。
2. 仍在使用能访问数据的兼容旧版时，更新前用旧版导出所需对话，并把工作区和配置复制到自己掌控的备份位置。对话回放文件不包含完整主目录、工作区或工具状态。
3. 已更新且没有备份时，保持 App 数据完整。普通文件管理器不能读取其他 App 的私有主目录；应按自己的设备和签名条件寻求恢复办法，不要为排障先卸载。
4. 手动把选定文件复制到可信远程主机前，私下检查备份，其中可能有 API Key、令牌和账号登录态。需要的凭据应在目标主机上明确重新配置，不要把整个主目录当成公开对话文件或诊断包分享。
5. 核对目标主机的绝对路径、工作区位置、插件兼容性和文件权限；确认结果可用前保留原始备份。

目前没有实现自动迁移、旧主目录导出向导或自动清理。删除保存的远程连接只删除该连接的设置和凭据，不删除远端文件或保留的旧主目录。卸载 App 或清除 Android App 数据会删除手机上的私有数据，只有明确决定并核验备份后再做。

连接设置和当前传输限制见 [远程主机](03-engine-hosts.md)。
