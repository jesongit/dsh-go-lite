# 在远程主机重载插件代码

[English](en/local-development.md)

修改实际被远端 DSH 加载的代码后，先运行插件自己的构建，再按那台主机的开发流程重启 `dsh web`。原来只适用于手机本机引擎的「重启内核以重载」入口已移除。App 不会替你同步目录或重启远端进程；重启前确认运行中的任务可以中断。

- SSH / DSH Remote 上的本地路径都属于远端主机，不属于手机。目录安装可能链接源码，也可能由包管理器复制；先确认实际加载的是哪份文件。
- 修改 `lib/` 时，应更新已加载的入口文件。卸载后重新安装、停用后重新启用均不能保证使 JavaScript 模块缓存失效。
- `package.json` 中的 `dshGo` 声明由 bridge 按修改时间重读；源码重载与声明重读是两件事。
- `cordis.patch.yml` 是否自动生效取决于主机的 HMR 配置。App 没有已核实的远程插件级 HMR 操作，不会擅自修改 `hmr.config.root`。
- 重连后查看插件详情、加载/解析诊断与主机日志；发起重启不等于插件已经成功运行。

安装和传输限制见 [主机覆盖](hosts.md)。
