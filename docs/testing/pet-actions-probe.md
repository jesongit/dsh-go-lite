# 远程客户端桌宠动作验收

旧的手机本机回环 Host 探针、专用 debug 入口和 smoke 脚本已随纯远程客户端转换退役。本页不再提供它们的构建、启动或操作命令。历史记录中的 smoke 1/1、受控返回文本和模拟器输入计划，只能说明当时夹具覆盖的范围，不代表当前 SSH / DSH Remote、真实语音模型或真机已经验收。

通用 UI 读取 helper `app/tool/build_pet_ui_dump.sh` 和配套 Java 工具保留，可按现有工具说明用于获授权设备的界面检查；它们不依赖旧的动作探针，不证明动作成功，也不能代替用户审批。

## 当前手动验收

先按 [贡献验证说明](../../CONTRIBUTING.md) 构建普通客户端，用兼容签名安装到获授权的 Android 测试设备；记录 App 构建号、Android/ABI、设备、主机 DSH/插件版本及实际连接路径。当前没有执行以下真机项目，不把桌面单元测试当作通过。

1. 分别明确选择 SSH 和 DSH Remote 主机，打开桌宠及系统悬浮窗权限。无主机、离线或登出时，应清楚表示不可用，不向另一台主机发送内容。
2. 在真实远程对话触发回复完成、错误、审批和问题。气泡与点击返回应定位正确主机/对话；切换主机、重连、请求过期后，旧气泡不能批准新的请求。
3. 测试「问一句」对当前对话和新对话的目标确认；手动发送后在对应主机核对记录。发送失败应保留文字，不能仅凭按钮消失认定发送成功。
4. 短且参数完整的审批与简单单选问题可在支持的气泡中处理；参数太长、不完整或需详细交互的请求进入 App。测试遮挡/注入防护，不能为自动化验收放宽生产审批策略。
5. 停止只作用于用户选定的远程对话。切换主机、断网或旧菜单失效时，核对没有停止其他主机的任务。
6. 语音按客户端实际提供的识别方式验收，分别记录录音权限、后台静音/拒绝、前台回退、识别文本和回填。回填不能自动发送；没有兼容离线识别能力时应明确不可用，不把旧手机 DSH 模型视为存在，也不擅自改送远端或云模型。
7. 覆盖 Android 后台限制、通知权限、浮窗权限拒绝及撤回、App 回前台后隐藏/恢复，确认桌宠服务与远端 DSH 进程独立。

保存必要的脱敏日志、主机回执和观察结果；真实模型、硬件麦克风、网络路径、Android API/OEM 未测的分别标明。诊断或截图外发前人工检查，不上传旧本地主目录或凭据。
